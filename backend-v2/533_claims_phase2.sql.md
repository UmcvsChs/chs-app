# 533 — Claims Phase 2 (applied live 18 Oct 2026)

Migrations `claims_phase2_a_schema_calc`, `claims_phase2_b_functions`.

- **Breakage allowance:** table claim_breakage_allowances (word in product name -> %; longest word wins; seeded block/sandcrete 2, floor tile/wall tile/tiles 3, cement/iron rod/roofing 0). `_claim_calc` withholds floor(quantity x %) units on "damaged" claims when the admin has not typed an amount (admin can override with a partial refund). Functions: admin_set_breakage_allowance, admin_remove_breakage_allowance, get_breakage_allowance(order) (buyer form note).
- **Replacement with its own code:** a trigger gives every replacement_pending claim a 6-digit replacement_code (buyer sees it only). seller_mark_replacement_sent(claim, note, method, rider, phone) records how it travels; seller_confirm_replacement_code(claim, code) or buyer_confirm_replacement closes the case.
- **Returns:** admin_decide_marketplace_claim(...,p_return_to 'chs_centre'|'seller'). Trigger sets return_code and a 7-day return_due_at. claim_confirm_return_received(claim, code, condition) is used by the seller (if return goes to the seller) or CHS staff; status return_received; admin then approves the refund with admin_confirm_claim_return (second approver rule still applies). get_claim returns the destination (seller pickup address, or the active CHS hub of the buyer's city). Sweep flags returns not made in 7 days (return_overdue).
- **Seller claim rate:** get_vendor_claim_stats (seller), admin_seller_claim_rates (admin). Sweep warns a seller once per 30 days above claim_warn_rate and flags listing review (marketplace_vendors.claim_review_flag) above claim_review_rate, notifying admins.
- **Delivery Protection Fund:** table delivery_fund_entries (manual top-ups/adjustments); admin_fund_summary = insurance collected (shipments.insurance_fee) + entries - fund_paid on decided claims; admin_add_fund_entry; admin_set_claim_setting edits any claim_* setting (audited).
- Tested in a rolled-back block: allowance (20 broken of 450 blocks -> 9 absorbed, 11 refunded = ₦4,950), wrong/right return code, return received then refund (₦5,247 incl. buyer commission), replacement wrong/right code, stats, fund summary, rates, sweep.
